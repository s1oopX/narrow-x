## 已修复 — 批次 2(服务端与前端行为)

**server/deploy-webhook.mjs**:部署子进程超时看门狗(`DEPLOY_TIMEOUT_MS`,默认 600000,SIGTERM→SIGKILL);部署期间的 push 改为 202 排队、结束后自动补跑一轮(多次 push 合并);子进程环境变量白名单(secret 不再进入构建环境);HMAC 签名 24h 去重防重放。自检覆盖以上全部新逻辑。

**server/oauth.mjs**:启动时校验全部必需 env(缺失则退出);token 格式白名单校验(`/^[\w.\-]+$/`)后才注入回调页;每次回调记录 allow/deny 日志(不含 token);`getSetCookie()` 正确转发多 cookie。

**deploy/nginx.conf**:全局安全头(nosniff、Referrer-Policy、X-Frame-Options、HSTS,已处理 add_header 继承陷阱);按实际外部源写的 CSP(giscus;admin 单独 CSP 含 unpkg + `X-Frame-Options DENY`);`/oauth`、`/deploy/github` 增加 limit_req。**上线前必须在 VPS 上 `nginx -t`。**

**deploy/*.service**:`ProtectSystem=strict`、`SystemCallFilter=@system-service` 等加固(未加 `MemoryDenyWriteExecute`,会破坏 Node JIT);服务改从 root 持有的 `/opt/narrow-x/services/` 运行(迁移步骤见 `docs/vps.md`)。上线后实测:原生 tsc(TypeScript 7)在构建中探测 `fanotify_init`(syscall 300)被 seccomp SIGSYS 击杀(exit 159),补充 `SystemCallErrorNumber=EPERM` 使白名单外调用返回 EPERM 而非击杀,工具链正常降级,已验证修复。

**scripts/deploy-vps.sh**:磁盘空间预检(`DEPLOY_MIN_FREE_MB`,默认 2048);部署后 `pnpm store prune`;`timeout 300 git fetch`;`merge --ff-only` 改为 `reset --hard`(容忍 force-push);锁竞争 exit 1;健康门禁增加站点根路径 200 + `<html` 校验。

**scripts/rollback-vps.sh**:容忍 `current` 符号链接缺失;无参回滚只选严格更旧的 release(消除来回切换)。

**check 脚本**:check-links 解析 srcset;check-assets 缺失资源友好报告;check-production 的「已保护」判定收紧为 401/403 或跳转到认证域(`SMOKE_AUTH_HOST`,默认 cloudflareaccess.com)。

**前端行为**:Mermaid 逐图 try/catch(单图错误不再中断整页)+ 色彩模式未变时跳过重渲染(消除每页双渲染);图库先等 chunk 加载成功再动 DOM、broken image 立即 settle(不再整组挂起);tabs 作用域限定到所属组(嵌套不再互扰);TOC 初始滚动位即计算激活项、滚过顶部清除激活;归档筛选 JSON.parse 防护 + popstate 单次注册;阅读进度 rAF 节流 + 无元素时不注册监听;搜索输入 150ms 防抖 + 失败后每次打开仅重试一次;login/dock 回退路径 base 感知,返回键校验 referrer 同源。

**测试基建**:Playwright webServer 先 build 再 preview,失败留 trace/截图;冒烟测试与具体内容解耦(动态取文章/分类);屏蔽全部非 localhost 请求;新增 3 个用例(色板切换持久化、归档 query 筛选、搜索索引 404 失败态)。6/6 通过。
